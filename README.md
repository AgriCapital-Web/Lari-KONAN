# Lari KONAN — Site personnel

Site vitrine personnel, inspirant et responsive autour de l'identité, des valeurs humaines, de la féminité, de l'évolution et du parcours de Lari KONAN.

## Pages du site

- `index.html` — Accueil
- `apropos.html` — À propos
- `valeurs.html` — Valeurs humaines et féminité
- `evolution.html` — Vision et cheminement personnel
- `parcours.html` — Parcours, apprentissages et aspirations
- `inspirations.html` — Pensées et repères pour le cheminement personnel
- `contact.html` — Contact direct par téléphone et e-mail

## Structure technique

- `assets/site.css` — styles partagés, responsive et animations
- `assets/site.js` — navigation mobile, animations d'apparition et année dynamique
- `assets/favicon.svg` — favicon du site

Le site est statique (HTML, CSS et JavaScript), sans base de données ni framework. Les pages partagent la même navigation, feuille de style et logique JavaScript.

## Vérifications avant publication

- Remplacer les photos d'illustration par les photos définitives choisies et autorisées par Lari.
- Relire les textes et personnaliser les passages qui doivent refléter précisément son vécu.
- Vérifier que les coordonnées de contact publiées sont toujours celles souhaitées.

Les images de démonstration sont des images distantes temporaires. Aucun diplôme, emploi ou témoignage non confirmé n'est revendiqué.

## Déploiement Vercel

Importer le dépôt GitHub et configurer le projet comme site statique :

- Framework preset : **Other**
- Build command : laisser vide
- Install command : laisser vide
- Output directory : `.`

La page d'entrée est `index.html`. Aucun serveur, build ou base de données n'est nécessaire. Les polices et images externes nécessitent une connexion Internet.
