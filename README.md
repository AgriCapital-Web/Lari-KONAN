# Lari KONAN — Site personnel

Site vitrine personnel, inspirant et responsive autour de l'identité, des valeurs humaines, de la féminité, de l'évolution et du parcours de Lari KONAN.

## Pages

- `index.html` — Accueil
- `apropos.html` — À propos / histoire personnelle
- `valeurs.html` — Valeurs humaines et féminité
- `evolution.html` — Vision et cheminement personnel
- `parcours.html` — Parcours, apprentissages et aspirations
- `contact.html` — Contact (coordonnées à ajouter après validation)

## Structure

- `assets/site.css` — styles partagés et responsive
- `assets/site.js` — menu mobile et animations d'apparition

Le site est statique (HTML, CSS, JavaScript), sans base de données ni framework. Il peut être hébergé sur GitHub Pages ou Vercel en tant que site statique.

## À personnaliser avant publication

1. Remplacer les photos d'illustration par les photos autorisées et choisies par Lari.
2. Vérifier et personnaliser les textes avec ses propres mots et ses valeurs réelles.
3. Ajouter son adresse e-mail ou son numéro de contact uniquement après validation.
4. Compléter les informations de formation et d'expérience si elle souhaite les publier.

Les images actuellement référencées sont des images temporaires distantes. Aucun diplôme, emploi, témoignage ou contact fictif n'est revendiqué.


## Publication

Le site est un site statique multi-pages. Pour Vercel, importer ce dépôt et utiliser :
- Framework preset : Other
- Build command : laisser vide
- Output directory : `.`
- Install command : laisser vide

Le fichier `index.html` est la page d'entrée. Aucun serveur ni base de données n'est requis. Les polices Google et les photos d'illustration nécessitent une connexion Internet.
